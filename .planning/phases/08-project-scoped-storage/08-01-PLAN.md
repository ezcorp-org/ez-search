<objective>
Move per-project index storage from `~/.ez-search/<basename>-<hash>/` into `<project>/.ez-search/` and relocate the manifest from `<project>/.ez-search-cache` to `<project>/.ez-search/manifest.json`.

Purpose: Project-scoped storage makes indexes portable and discoverable. No more global hash directories that are invisible to the user.

Output: All index data (vectors, manifest, schema version) stored inside the project directory at `.ez-search/`.
</objective>

export function resolveProjectStoragePath(projectDir: string): string {
